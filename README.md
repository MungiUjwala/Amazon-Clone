# Amazon Frontend Clone

This project is a responsive Amazon homepage clone created using HTML and CSS.  
It replicates the basic layout and design of the Amazon website, including the navbar, product sections, banners, and footer.

## Features
- Responsive web design
- Amazon-style navigation bar
- Product cards and sections
- Clean UI layout
- Footer design similar to Amazon

## Technologies Used
- HTML5
- CSS3

## Purpose
This project was built to improve frontend development skills and practice responsive web design concepts.

## Future Improvements
- Add JavaScript functionality
- Create login/signup pages
- Add shopping cart features
- Improve mobile responsiveness
